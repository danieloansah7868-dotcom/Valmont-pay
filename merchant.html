Valmont-Pay Merchant Settings

Sign in

Paste a secret key. It is sent as Authorization: Bearer and kept in this tab's sessionStorage only — never written to a cookie or a URL.

Your keys are printed in the server log the first time the gateway boots, and can be pinned with the VALMONTPAY_TEST_SECRET_KEY / VALMONTPAY_LIVE_SECRET_KEY environment variables.

API keys

Public keys are browser-safe. Secret keys authorise initialize and verify, and sign your webhooks — keep them server-side only.

Webhook endpoint

Every terminal state (charge.success, charge.failed, refund.processed) is POSTed here, signed with x-valmontpay-signature (HMAC-SHA512 hex over the raw body, keyed with your secret key). Retried with exponential backoff for ~24h until you return a 2xx. Live URLs must be HTTPS.

Webhook deliveries

A replay re-sends the identical body with the same x-valmontpay-event-id, so your handler sees one logical event no matter how many attempts it takes.
