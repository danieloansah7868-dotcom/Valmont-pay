API Reference

POST /api/transaction/initialize

Authorised by tenant secret key. Initializes a payment and returns an access_code.

Authorization: Bearer <secret_key>
Content-Type: application/json

{
  "amount": 50.00,
  "reference": "VM-ORDER-123",
  "currency": "GHS",
  "email": "customer@example.com",
  "phone": "+233501234567",
  "callback_url": "https://valmontweb.com/orders/thanks"
}

→ 200
{
  "status": true,
  "data": {
    "access_code": "ac_1a2b3c4d5e6f7g8h",
    "reference": "VM-ORDER-123",
    "amount": 50.00,
    "currency": "GHS",
    "pay_url": "https://valmontpay.app/pay.html?access_code=ac_..."
  }
}

GET /api/transaction/verify/{reference}

Verify a transaction. Tenant-scoped — returns 404 for cross-tenant lookups.

Authorization: Bearer <secret_key>

→ 200
{
  "status": true,
  "data": {
    "reference": "VM-ORDER-123",
    "status": "success",
    "amount": 50.00,
    "currency": "GHS",
    "channel": "mobile_money",
    "paid_at": "2025-06-15T12:00:00Z",
    "merchant": "valmont-electricals",
    "gateway_reference": "VM-ORDER-123"
  }
}

Webhook: x-valmontpay-signature

Every event is POSTed to the tenant's webhook URL, signed with HMAC-SHA512 using the tenant's Paystack secret key.

POST <tenant_webhook_url>
Content-Type: application/json
x-valmontpay-signature: <HMAC-SHA256(secret_key, raw_body)>

{
  "event": "charge.success",
  "data": {
    "reference": "VM-ORDER-123",
    "status": "success",
    "amount": 50.00,
    "currency": "GHS",
    "channel": "mobile_money",
    "paid_at": "2025-06-15T12:00:00Z",
    "merchant": "valmont-electricals",
    "gateway_reference": "VM-ORDER-123"
  }
}

Return Redirect

After Paystack checkout, the customer is redirected to the callback_url with status params.

GET /api/transaction/return?reference=VM-ORDER-123&status=success&merchant=valmont-electricals&callback_url=https://valmontweb.com/orders/thanks

→ 302 Redirect to:
https://valmontweb.com/orders/thanks?ref=VM-ORDER-123&status=success
