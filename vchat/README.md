# 🗨️ VChat

Real-time messaging app with rooms, DMs, file sharing, typing indicators, read receipts, and recycle bin.

## Quick Start

```bash
npm install
npm start
```

Open **http://localhost:3000**

## Features

- 💬 Real-time messaging via WebSockets
- 👥 Group chat rooms
- ✉️ Direct messages
- ✍️ Typing indicators
- ✅ Read receipts
- 📎 File/image sharing
- 🟢 Online/offline status
- 🔍 Search
- 🗑️ Recycle bin (soft-delete & restore)
- 🎨 Valmont brand theme
